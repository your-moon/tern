# tern landing page

Plain static HTML, CSS and JavaScript, no build step.

| File | What it holds |
| --- | --- |
| `index.html` | Every word on the page. Each platform's hero button and small print is its own block (`data-platform="mac"`, `windows`, `linux`, `other`). |
| `main.js` | Behaviour only: shows the visitor's platform block, points download links at the latest release, shows the star count, and runs the screenshot tabs. |
| `style.css` | Grouped top to bottom like the page: tokens, base, buttons, header, hero, features, tabs, memory chart, sync diagram, downloads, footer, screen sizes. |
| `assets/icons.svg` | Icons by name, used as `<svg><use href="assets/icons.svg#apple"/></svg>`. |
| `assets/hero.png` | The hero picture, generated by `tools/make_hero.py` (not deployed). |
| `assets/*.jpg` | App screenshots, copied from `docs/screenshots/`. |

Download links carry `data-asset="macos-arm64.dmg"` and so on: `main.js` rewrites them to the latest release's file names, so a new release needs no edit here. The static `0.1.3` links are the fallback when GitHub's API doesn't answer.

Regenerate the hero picture (Red Fuji, cropped from 15% down):

    python3 site/tools/make_hero.py crates/tern/assets/wallpapers/red-fuji.jpg site/assets/hero.png 1920 560 0.15

Preview: `python3 -m http.server -d site`, then open http://localhost:8000. Add `?os=windows`, `linux` or `other` to see the other hero variants.

Deploy: `site/deploy.sh` (rsync to grape-2). It serves from the `carrot-soft-tern` nginx container behind Traefik at https://tern.carrot-soft.tech.
